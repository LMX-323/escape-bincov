# 逃离滨科夫 · 游玩手册

台风与赤潮封锁了滨科夫县。你从水产站出发，搜集补给、避开危险，在 **10 分钟内撤离**，把装备和物资带回来。

当前版本为 0.2.0，包含一张地图、三项任务和单人游戏流程。桌面使用键盘与鼠标；手机触控开放尝鲜，iPhone/Android 真机验收待补。完整更新内容见 [v0.2.0 发版公告](releases/v0.2.0.md)。

## 开始游玩

**在线：** 用电脑端 Chrome 或 Edge 打开 [在线试玩](https://xuys2025.github.io/escape-bincov/)。首次加载需要网络，无需账号。

**离线：** 解压 `release/Escape-Bincov-portable.zip`，用 Chrome 或 Edge 打开 `start the game.html`。这个 HTML 已包含完整游戏，可单独复制或分享，无需安装、服务器或联网。若双击后打开了编辑器，右键选择「打开方式 → Chrome 或 Edge」。

建议窗口为 1280×720 或 1920×1080。主界面按窗口排布；桌面水产站与行动画面使用 960×540 逻辑尺寸，手机控件独立按屏幕排布，窗口边缘可能留有黑边。首次点击后才会播放声音，可在「水产站」页或暂停菜单调整「游戏音量」。

## 第一局

1. **整备。** 点击「进入水产站」，在「整备」中检查主武器，把备用弹药、绷带或急救包放入背包。商店买到的物资先放入仓库，需要自行转移。
2. **出击。** 点击「出击」，按 `M` 查看本局两个绿色撤离点。每局有 25 名敌人和 60 件初始地面物资，枪声会引来附近的敌人。
3. **搜集物资。** 靠近物资按 `E` 拾取，按 `Tab` 整理背包。重要的小件可以放入安全箱。背包和地图打开时，行动继续。
4. **撤离。** 在本局绿色撤离圈内站稳，按住 `E` 满 **3 秒**。回站后可出售物品、交付任务、整理装备，再次出击。

## 手机触控候选版

整备支持横竖屏，战斗需要横屏。左盘移动、外圈冲刺；右盘内圈瞄准、外圈持续开火，松开停止。靠近物资点击「拾取」，在绿色圈内站稳，按住「撤离」3 秒。治疗、换弹、武器切换、地图、背包和暂停均有按钮。旋转、切到后台会暂停，回到游戏后点击继续。

手机点选物品查看操作；仓库可切换列表或格位整理，不必拖动或双击。地图和背包仍不暂停行动。当前状态和验收边界见 [移动实现](MOBILE-IMPLEMENTATION.md)。

## 桌面操作

| 按键 | 动作 |
| --- | --- |
| `W A S D` | 移动 |
| 鼠标移动 / 左键 | 瞄准 / 攻击 |
| 右键 | 精瞄 |
| `Shift` | 冲刺，消耗耐力 |
| `R` | 换弹，使用背包中的对应弹药 |
| `1` / `2` | 切换主武器 / 水手匕首 |
| `E` | 拾取物资或阅读留言 |
| 按住 `E` 3 秒 | 在本局绿色撤离圈内站稳后撤离 |
| `Q` | 使用背包中的绷带或急救包 |
| `Tab` / `M` | 打开或关闭背包 / 地图，均不暂停行动 |
| `Esc` | 关闭当前面板；没有面板时暂停行动 |

按 `Q` 治疗时，流血且背包有绷带就先用绷带，否则优先用急救包，再用绷带。除藻药剂、净水瓶和鱼松罐头需要在背包面板中选中，点击「使用」。

## 潮位与身体状态

出击 **4 分 30 秒**后，电台会发出潮汐预警；**5 分钟**时，潮位由高变低或由低变高。这里指从出击开始计算的时间。浅滩捷径和部分物资会随潮位开放或被淹，高架路与海堤始终可通行。

涉水会积累污染，污染过高会损失生命。流血会持续损失生命，需要止血。医疗用品和食品的效果如下：

| 物品 | 效果 |
| --- | --- |
| 密封绷带 | 止血，恢复 16 点生命 |
| 急救包 | 止血，恢复 55 点生命 |
| 除藻药剂 | 降低 55 点污染 |
| 净水瓶 | 恢复全部耐力，降低 12 点污染 |
| 鱼松罐头 | 恢复 12 点生命和 50 点耐力 |

## 仓库、背包与装备

- **仓库**保存留在水产站的物资，初始为 10×6 格。
- **背包**为 6×5 格，其中的物资会带入行动。
- **安全箱**为 2×2 格，其中的物品在撤离失败后也会保留。
- 单击物品查看用途和操作，拖动整理位置。在「整备」中双击可在仓库与背包间转移；也可用详情中的「放入背包」「放入仓库」「放入安全箱」按钮。
- 物品不能旋转，同类物品可按堆叠上限合并。格子中的短名称与物品详情中的全名指同一物品，例如「除藻剂」即「除藻药剂」。

**负重包含背包、安全箱、主武器、水手匕首和枪内子弹。** 超过 24 kg 会减慢移动，并增加冲刺的耐力消耗。

主武器需要先装备。行动中可以在背包面板中装备搜到的枪；水手匕首始终可用。换弹只使用背包中的弹药，安全箱里的弹药要先转入背包。

成功撤离会保留枪内子弹。换枪或卸下主武器时，会尝试放回原枪及其子弹；空间不够就不执行操作。救济子弹不可出售，装填、换枪和卸枪都不会改变这一点。

## 商店与任务

老栓的「修理铺」出售武器、弹药和零件；许医生的「卫生所」出售医疗用品和食品。购买的物资放入仓库。出售时，在「整备」中选中物品，点击「出售」；救济物资不可出售。

「电台任务」中的三项任务可以从仓库、背包和安全箱交付物资，交付后会扣除所需数量。

| 任务 | 所需物资 | 报酬 |
| --- | --- | --- |
| 让灯亮起来 | 泵机零件 ×3、绝缘线圈 ×2、陶瓷保险管 ×1 | ¥420，解锁仓库扩建 |
| 瓶中的潮声 | 赤潮封存样本 ×1，位于潮汐观测站 | ¥650 |
| 未归的第七艘船 | 港口船册 ×1，位于旧渔港 | ¥800 |

完成「让灯亮起来」后，可在「水产站」页花费 **¥600 扩建仓库**，容量从 10×6 格增至 10×9 格，只能扩建一次。

## 撤离失败与救济物资

成功撤离保留装备和物资。**死亡、超时或主动放弃会丢失背包内的物资和主武器，安全箱内的物品与水手匕首保留。** 新版行动关闭或刷新后，可从主菜单继续最近成功保存的进度，少量未保存内容可能回退；无世界快照的旧版行动仍按失败处理。

没有枪械且现金低于 ¥200 时，水产站会提供救济手枪、12 发子弹和绷带，均不可出售。背包或仓库空间不足时，未领到的物资会留在水产站；腾出空间后，可在「整备」点击「领取救济补给」。同一批救济物资不会重复发放，也不会在行动中自动补入背包。

## 存档与备份

进度保存在**当前浏览器**中，不是云存档。新版主记录为 `escape-bincov.session.v2`，旧 `escape-bincov.save.v1` 首次迁移后保留原始字节；未知或损坏的记录不会被当作空档覆盖。更换浏览器、游玩地址或 HTML 文件路径，可能会读到另一份进度；清理浏览器数据可能删除存档。请使用原浏览器和固定路径游玩，不要从 ZIP 预览的临时目录启动。

更换入口前：

1. 结束行动，在「水产站」页点击「导出存档」，确认 JSON 文件下载完成。
2. 打开新入口，进入同一页，点击「导入存档」并选择备份。
3. 核对现金和累计出击次数，确认后导入。**导入会覆盖该入口现有的进度，两个存档不会合并。** 写入失败时仍保留原存档。

行动暂停菜单可导出包含完整局内状态的行动备份，在水产站确认导入后，从主菜单继续。遇到「结算尚未保存」时，行动已经结束，但本次结果只暂存在当前页面。可以重试保存，或下载包含本次结果的结算备份。**保存成功或确认备份下载完成前，不要关闭或刷新页面。** 结算备份也通过「导入存档」恢复，会覆盖该入口的现有进度。

另一个窗口更新存档时，本页会停止操作，防止覆盖。若当前有未保存的结算，先下载结算备份；重新加载后，选择需要保留的进度再导入，不会自动合并两个窗口的结果。

从旧 0.1.0 本地文件升级时，先把新版 HTML 覆盖到原路径，再用原浏览器打开并导出；不要先移动或删除原文件。浏览器禁止保存数据时，游戏会提示保存失败并阻止出击。

## 重现同一局配置

「整备」底部的「行动种子」留空时随机生成，也可输入数字或文字。相同种子可以重现出生点、初始潮位、撤离点组合、敌人和地面物资的初始配置；玩家操作仍会影响结果。

## 版本与其他说明

这是仍在开发中的单人游戏，手机触控已实现候选版；手柄、多人联机和云存档尚未实现。主界面适配范围见 [主界面记录](TITLE-SCREEN.md)。

在线试玩使用 GitHub Pages，离线包和网页包来自同一份源码。构建、测试和贡献方法见 [README](../README.md) 与 [开发手册](AGENT-HANDBOOK.md)；历史完整流程验收见 [验收记录](ACCEPTANCE.md)，最新检查以对应提交的 GitHub Actions 为准。大陆网络下的访问与备用托管说明见 [在线游玩指南](ONLINE-CHINA.md)。

人物、建筑、物品和声音由游戏代码生成，不依赖外部素材或 CDN。地名、组织和人物均为虚构。Phaser 与 EventEmitter3 的许可声明已内嵌在 HTML 中，另见 [第三方声明](../THIRD_PARTY_NOTICES.md)；原创源码的许可状态未改变。
