# 逃离滨科夫 · Escape Bincov 0.1.1

本地运行、单人键鼠、2D 俯视角像素撤离生存原型。超强台风与异常赤潮封锁了虚构的滨科夫县。你从废弃水产站出发，穿过城中村、水产市场与旧渔港，在封锁窗口关闭前把物资带回来。

## 0.1.1 更新

- 结算先保存再显示完成。保存失败会暂停并保留待保存结果，可重试或下载完整结算备份。
- 交易、任务、拖放、安全箱物品操作保存失败时回退，不显示成功。
- 水产站新增存档导出与确认导入，支持本地文件和在线域名之间迁移。
- 修复打开暂停、背包及结算待保存面板时 HUD 短暂回到初始值的问题。
- 补齐主目录启动入口；新增根目录为 `index.html` 的网页上传包。

## 直接游玩

在线入口：[GitHub Pages 试玩](https://xuys2025.github.io/escape-bincov/)。也可按下面方式离线启动。

双击主文件夹里的 **`start the game.html`**，用桌面版 Edge 或 Chrome 打开，点击「进入水产站」即可开始。它是完整的便携游戏文件，不依赖原电脑路径；`dist/index.html` 也仍然可用。发布文件约 1.51 MiB，内含游戏代码、样式和 Phaser；像素图形与声音由内置程序生成。游玩不需要服务器、网络、Node.js 或安装游戏引擎。

建议窗口为 1280×720 或 1920×1080。游戏使用 960×540 逻辑画面，以整数倍显示并保留黑边。首次点击后才会开启声音；可在水产站设置或暂停界面调整音量。

## 打包分享

直接发送 `release/Escape-Bincov-portable.zip`；对方解压后双击 `start the game.html` 即可游玩。也可以只发送主文件夹中的 `start the game.html`，因为它本身已包含完整游戏。旧版 `start the game.lnk` 指向本机绝对路径，现已由便携 HTML 入口替换。

分享包只含完整游戏 HTML 和中文游玩说明，不携带浏览器存档。收件人可把文件放到任意目录；已有玩家为继续原存档，应保持原浏览器与原 HTML 路径。若系统把 HTML 关联到了编辑器，右键选择 Chrome 或 Edge 打开。

更新源码后在项目目录执行 `pnpm package`，会重新构建两个一致的 HTML 并用 Node 内置功能生成标准 ZIP；`pnpm test:portable` 检查解压到全新目录后仍能离线启动。对方游玩不需要任何开发或打包工具。

网页部署使用 `release/Escape-Bincov-web.zip`，其中根目录直接是 `index.html`；无需在托管平台安装 Node 或构建源码。大陆访问的部署选择见 [上线调研](ONLINE-CHINA.md)。

## 第一局

1. 在「装备整备」检查主武器、背包弹药和绷带。点击物品查看说明，拖放整理；双击在仓库与背包间转移。购买物资先进入仓库，要装进背包才会带入行动。
2. 点击「出击」。按 `M` 查看本局的两个绿色撤离点，沿道路探索。每局限时 10 分钟，地图上有 25 名敌人与 60 件初始地面物资。
3. 靠近物资按 `E` 拾取；枪声会吸引附近敌人。用 `Tab` 整理背包，把重要的小件物资放入安全箱。背包和地图打开时行动继续。
4. 到达本局启用的绿色撤离标记，在圈内停稳并按住 `E` 满 3 秒。返回水产站后可转移物资、出售、交任务，再次整备出击。

每次出击在第 4 分 30 秒收到潮汐预警，第 5 分钟潮位翻转。浅滩捷径和部分高价值物资会随潮位开放或被淹没；海堤、高架道路和码头主通道始终保留。涉水会增加异常污染，绷带用于止血，急救包补充生命，除藻药剂降低污染。

## 操作

| 按键 | 动作 |
| --- | --- |
| `W A S D` | 移动 |
| 鼠标移动 / 左键 | 瞄准 / 射击或近战 |
| 右键 | 精瞄 |
| `Shift` | 冲刺，消耗耐力 |
| `R` | 从背包弹药换弹 |
| `1` / `2` | 主武器 / 基础匕首 |
| `E` | 拾取、阅读环境文字；撤离区内按住 3 秒撤离 |
| `Q` | 快捷治疗 |
| `Tab` | 行动背包，不暂停 |
| `M` | 地图，不暂停 |
| `Esc` | 关闭面板或暂停 |

背包为 6×5 格，安全箱为 2×2 格。物品不能旋转，同类物品可按上限堆叠；拖放到有效位置可整理或转移。总负重包含背包、安全箱、主武器、基础匕首与弹匣子弹；超过 24 kg 会减慢移动并增加冲刺耐力消耗。备用武器要先装备才能使用，行动中可在背包物品详情装备搜到的枪，水手匕首始终保留。

成功撤离会保存枪内剩余子弹，不要求把弹匣倒回背包。卸枪或换枪会尝试返还原枪弹药；容纳不了旧枪和子弹时，操作保持原状。普通子弹和救济子弹分开记录来源，换枪或卸弹不会让救济子弹变成可出售物资。

## 局外进度与存档

- 老栓经营武器零件，许医生提供医疗补给。可以从物品详情出售物资；救济物资不可出售。
- 三项任务需要修复水产站、带回赤潮样本、找到港口船册。维修需零件 ×3、线圈 ×2、保险管 ×1；任务可从仓库、背包与安全箱交付。
- 完成维修后可花费 ¥600 扩建一次储物架，仓库从 10×6 格增加为 10×9 格。
- 成功撤离保留携入装备和搜刮所得；死亡、超时或主动放弃失去背包及主武器，安全箱和基础匕首保留。
- 没有枪械且现金低于 ¥200 时，系统提供不可出售的救济手枪、12 发子弹和绷带。若背包与仓库都没有空间，尚未发出的补给会留在水产站；腾出空间后可在整备页点击「领取救济补给」，不会反复生成或自动混入行动背包。

存档保存在当前浏览器的本地存储，键为 `escape-bincov.save.v1`，包含仓库、现金、装备、任务、升级和设置。出击前先记录携带物资已离开仓库；**刷新或关闭未结算的行动，下次打开按撤离失败处理**。安全箱的变更会及时保存，结算不能重复领取。

可在「水产站」页导出 JSON 存档，换文件或网页后在同一页导入。导入需确认覆盖，并且只有写入成功才替换当前进度；存档不包含正在进行的行动。结算写入失败时可下载包含本次结果的备份，关闭页面前应先确认下载完成。

旧 0.1.0 本地存档：先将新版 HTML 覆盖到原 HTML 的相同路径，再用原浏览器打开并导出；不要先移动或删除原文件。

请在同一浏览器、同一文件位置继续游玩。移动 HTML 文件、更换浏览器、使用不同本地服务器地址或清理浏览器数据可能对应另一份存档。浏览器禁止本地存储时，游戏会提示且不会启动出击。

整备界面的「行动种子」可留空随机，也可输入数字或文字。相同种子复现出生点、初始潮位、撤离组合、敌人与地面战利品配置；玩家操作仍会改变战斗结果。

## 源码开发

推荐 Node.js 24 和 pnpm 11。安装依赖需要网络，生成后的游戏不需要网络。

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

开发地址：`http://127.0.0.1:4173`。修改源码后刷新页面会重新构建。

```powershell
pnpm build         # 类型检查，并生成独立 dist/index.html
pnpm test          # 领域规则、随机配置与地图可达性测试
pnpm test:browser  # 浏览器流程与显示检查
pnpm test:save-browser # 保存失败、导入导出、任务和升级界面回归
pnpm test:play     # 约 10 分钟真实计时自动玩家（只读状态，真实键鼠）
```

浏览器测试优先使用 Windows 标准 Chrome 路径，否则使用 Playwright 已安装的 Chromium。可用 `BINCOV_CHROME` 指定可执行文件，`BINCOV_CHROME_ARGS` 提供 JSON 数组格式的额外参数。Linux/macOS 的 ZIP 解压验证还需要 Python 3；Windows 使用 .NET ZIP API。它直接打开构建后的 `file:` HTML，不需要先启动开发服务器。`node scripts/browser-test.mjs --smoke` 可执行快速启动检查。截图与报告写入 `test-results/`；实测记录见 [验收文档](ACCEPTANCE.md)。仅游玩发布文件不需要这些开发依赖。

## 项目结构

| 文件 | 职责 |
| --- | --- |
| `src/main.ts` | Phaser 初始化、场景入口、画面缩放 |
| `src/game.ts` | 行动场景、移动战斗、敌人 AI、潮汐、撤离 |
| `src/ui.ts`、`src/style.css` | 主菜单、整备、商人、任务、背包与结算界面 |
| `src/domain.ts` | 纯领域逻辑与数据表：物品、武器、敌人、交易、任务、存档和结算 |
| `src/balance.ts` | 生存数值：负重、速度、耐力、流血、污染、治疗和撤离时间 |
| `src/world.ts` | 手工地图、种子配置、碰撞、视线与独立寻路 |
| `src/art.ts`、`src/audio.ts` | 原创程序像素图形与合成声音 |
| `tests/` | Node 单元测试 |
| `scripts/build.mjs` | esbuild 打包及本地开发服务 |
| `scripts/browser-test.mjs` | 浏览器自动检查 |
| `dist/index.html` | 可独立复制和打开的发布文件 |

状态流为「主菜单 → 藏身处 → 行动 → 结算 → 藏身处」。规则层不依赖 Phaser；`ItemDef`、`WeaponDef`、`EnemyDef`、`LootTable`、`RunConfig`、`SaveDataV1` 为主要数据接口。地图尺寸为 72×52 格，每格 32 像素；可达性测试独立于场景渲染。

## 验证与边界

0.1.1 已通过严格类型检查、47 项自动测试、双分辨率的 24 步浏览器回归、7 项存档专项浏览器检查及 6 项便携包检查。最新完整证据与边界见 [验收文档](ACCEPTANCE.md)；原始 0.1.0 验收见 Git 历史。

浏览器回归会通过定位和推进计时加速部分流程；另提供不改位置、不改生命与计时的真实计时自动玩家脚本，其结果不等同于人类玩家的耐玩性评价。

这是本地个人垂直切片，目标是约 10 分钟一局、约 30–60 分钟重复游玩；后者是体验目标，仍需实际试玩评价。当前仅支持桌面键鼠，不包含多人联机、移动端、手柄、云存档。在线试玩由 GitHub Pages 静态托管，仍为单人游戏。
