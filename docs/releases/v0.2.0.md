# 《逃离滨科夫》v0.2.0 更新公告：夜港归来

**发布日期：2026 年 10 月 4 日**

水产站的灯还亮着，这一次，回家的路更清楚了。

v0.2.0 汇集了前五个 PR 的更新：我们重新打磨了整备界面，重绘了风雨中的夜港，加入手机触控尝鲜和行动中断后的继续功能，也让物品说明、操作提示与存档保护更加清晰。熟悉的暗绿像素风和「带着物资活着回来」的单人撤离玩法继续保留。

**[在线试玩](https://xuys2025.github.io/escape-bincov/)** · **[版本与下载](https://github.com/xuys2025/escape-bincov/releases/tag/v0.2.0)**

## 整备更顺手，信息更好读

- 仓库、背包和安全箱中的物品名称与数量分开显示，减少挤在一起、看不清的问题。选中物品后，用途、属性和可执行操作更集中。
- 商店中的物品、整包数量和价格排列更清楚；电台任务显示实际收集进度，哪些已经可以交付更容易判断。
- 长内容可以在工作区内滚动，出击入口保持可见；扩建仓库后，底部物品也能正常查看和操作。
- 行动状态、地图、背包和提示窗口统一了排版，站内的状态、音量与备份入口也更容易找到。

## 在风雨夜港中，准备下一次出发

全新主菜单加入月光、云层、港口起重机、水产站暖窗、潮水倒影和码头上的归来者。标题、整备入口与电台短句重新布局，在桌面宽屏与手机横竖屏上都更清楚。

你可以关闭「动态景物」，界面也会遵循系统的减少动态效果设置。主菜单与行动指南支持更完整的键盘选择和返回操作。

## 手机触控开放尝鲜

现在可以直接使用屏幕控件体验游戏：

- **左摇杆移动，推到外圈冲刺；右摇杆内圈瞄准，推到外圈持续开火，松开停止。**
- 拾取、撤离、治疗、换弹、武器切换、背包、地图和暂停都有独立按钮。撤离时仍需在有效范围内停稳并按住按钮 3 秒。
- 整备支持横屏和竖屏，战斗需要横屏；整理物品可以点选物品和格位，也可以使用仓库列表，不必依赖拖拽或双击。
- 旋转屏幕或切到后台时会暂停，回来后再继续。打开背包和地图仍不会暂停行动。

**手机支持目前属于尝鲜阶段。** 已完成浏览器模拟触控检查，但 iPhone Safari、Android 真机的多指操作、来电等系统打断、声音、文件下载和长时间发热表现仍待验证；暂不承诺鸿蒙或微信内置浏览器的完整兼容。电脑端 Chrome / Edge 仍是当前推荐的游玩方式。

## 中断之后，可以继续上一次行动

新版会在行动中定期保存进度。刷新页面、关闭后重新打开，或页面被系统回收后，可以在主菜单选择「继续上次行动」，接着最近成功保存的位置继续探索。

恢复内容包含角色状态、装备与弹药、敌人、地面物资、潮位和剩余时间。**恢复的是最近一次成功保存的进度，最后少量未保存内容可能回退。** 没有完整行动记录的旧版存档，仍沿用旧版的中断处理规则。

这项功能不会改变失败规则：死亡、超时或主动放弃仍会丢失背包物资和主武器，安全箱内的物品与水手匕首保留。

## 存档更稳，提示更明确

我们整理了存档与结算流程，让拾取、丢弃和使用物品时的行动状态一起保存；保存失败时，相关操作会撤回，减少物品重复或消失的风险。结算未能保存时，会保留重试和下载备份的入口，不会把未保存的结果当成已经完成。

暂停菜单可以导出正在进行的行动备份。新版也加强了旧进度接续、异常存档识别和多个窗口同时游玩时的保护。**存档仍保存在当前浏览器中，不会自动同步到其他设备。**

物品、任务和按钮名称也做了统一：药品的用途更准确，流血时不会再出现矛盾的「状态稳定」提示；交易、治疗或物品移动无法完成时，会尽量告诉你具体原因。存档导入会明确提示覆盖当前进度，两个存档不会合并；导出后请确认备份已经下载完成。

## 桌面操作继续保留

原有键盘和鼠标操作继续可用，带触摸屏的电脑也不会仅因支持触摸就失去桌面操作。鼠标射击仍为按下单发，右键精瞄配合左键射击的方式不变。

本版还修复了用 Esc 继续行动时声音没有恢复，以及满血时尝试治疗会打断持续移动的问题；暂停、切出窗口和读档时仍会停止旧输入，避免恢复后角色自行移动。

## 下载与升级

普通玩家请在本版本下载区选择 **`Escape-Bincov-portable.zip`**，解压后用 Chrome 或 Edge 打开 `start the game.html`。它包含完整游戏和中文说明，无需安装、注册账号或联网游玩。在线版首次加载需要网络；自行托管网页可使用 `Escape-Bincov-web.zip`。

已有进度的玩家建议这样升级：

1. 升级前先导出存档，并确认备份文件已保存。正在新版行动中可从暂停菜单导出行动备份；不支持此功能的旧版应先结束行动，再导出。
2. 在线玩家继续使用原浏览器和原网址；离线玩家将新版放在原来的固定路径，再用原浏览器打开。不要从 ZIP 的临时预览目录启动。
3. 若更换浏览器、设备、网址或文件路径，请在新入口导入备份。导入会覆盖该入口已有进度，不会合并两份存档。

新版会接续可用的旧进度，并保留旧记录作为迁移备份；新版产生的进度请继续使用新版打开。仍在使用不支持导出的 0.1.0 时，应先在原路径升级，再导出备份。遇到「结算尚未保存」时，请先重试保存或确认结算备份已下载，再关闭页面。

游戏仍处于早期开发阶段，目前是一张地图、三项任务和完整单人循环，没有新增多人联机、云存档或手柄支持。大陆网络下在线入口的实际速度和可达性仍需实测，访问不畅时可以使用离线包。

欢迎通过 [问题反馈](https://github.com/xuys2025/escape-bincov/issues) 告诉我们你的体验；如遇异常，请尽量附上设备、浏览器、操作步骤和截图。详细规则见 [游玩手册](https://github.com/xuys2025/escape-bincov/blob/v0.2.0/docs/PLAYING.md)。

**整理装备。灯还亮着，等你回来。**
