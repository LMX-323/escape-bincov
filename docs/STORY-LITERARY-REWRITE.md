## 写作目标

让滨科夫的故事从设定清单变成值得阅读、能让人关心其中人物的叙事。可优先着力于县城生活的具体质感、灾后人的处境、人物之间的关系与矛盾，以及六阶段主线和三个结局的情绪积累。文学性的判断以实际文本为准，不靠增加修辞数量或篇幅完成。

叙述视角、结构、节奏和文体由后续作者发挥；本交接不预先代写故事。可以为人物补充经历、声音和生活细节，让不同势力的选择由具体人物与行动呈现。

## 设定与实施边界

以 #27 的已接受设定为起点：潮水封锁沿海县城、盐度与受盐、内陆区域扩展、现有势力关系、六阶段主线，以及逃离／封潮／留守三种选择。远汐号和失踪的第七艘船是不同对象；普通行动撤离回水产站，最终主线撤离才离开县城。

这些设定可在叙事中重新组织、充实和深化。如果更好的故事需要改变地图关系、据点数量、人物立场、剧情真相或结局条件，请在同一 PR 中明确列出取舍供维护者审阅。文学修订不能把新增游戏规则或 #26 中的未决建议写成已经确定、已经实现的事实。

本轮交付为故事文稿及必要的设定说明。玩法、地图、任务、盐度数值、存档、素材和发布的实际接入仍在 #22 完成后安排；文稿可以先行修订。#26 保持开放，文学重写不等于其中建议已全部解决。

## 续作与交付

作者可以直接重写原稿的叙事部分，也可以把故事正文放入独立文稿，让原设定文档保留地图、任务和实现边界的清晰索引。选择有利于阅读和后续开发的组织方式，避免出现两份互相矛盾的设定。

完成时在本 PR 提供重写文本和简要修订说明，指出保留、深化或提议调整的设定，校对人名、地名、时间线、主线线索和结局因果，并同步相关导航。维护者审阅文学效果后，再决定是否转为 Ready 和合并。
