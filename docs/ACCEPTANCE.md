## 真实计时自动玩家

持续约 619.0 秒；使用真实键鼠输入，仅读取状态进行寻路和瞄准，没有修改时间、位置、生命、敌人、背包或随机数。完成 2 次行动，结果为 extract、extract，累计击杀 34。第一局自然经过第 5 分钟的潮汐翻转，随后正常撤离并再次出击；本次无页面异常或外部网络请求。

自动玩家会直接读取地面物资和敌人位置，并进行较准确的瞄准，因此其效率不代表普通玩家。第一局后段已清空固定敌人并在撤离附近等候，不能将本次记录解释为全程高强度战斗。它验证持续运行、自然计时和循环流程，不能替代 30–60 分钟真人对手感、平衡和耐玩性的评价。详见 `natural-play-report.json`。

## 性能与边界

基础浏览器脚本保留了 5 秒性能样本，运行于共享 CPU 与软件渲染环境；不据此承诺玩家设备的帧率。当前未做真实 Windows/Edge 设备、手机触控、手柄、多人、云存档或大陆三网公网部署验收。

存档异常测试验证了显式写入失败时的回退、暂停和备份；若玩家在保存失败后既不重试也不下载备份而强行关闭页面，内存中的待保存结算仍会丢失，界面已明确提示。

开发过程中的环境失败（浏览器下载、单进程浏览器上下文退出）已通过独立测试环境处理；上表和 JSON 对应最终成功复测。
