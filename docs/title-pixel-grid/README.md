# 主菜单统一像素网格与共享色板（v7）

2026-10-07。基线 `425f320`（#21 已合并）。用户反馈：#21 的标题画面精美，但“AI 味”重。

## 原因

#21 的运行图层是生成插画直接缩到 960×540，不是像素画。抽样结果：room 层 58,391 色，95% 的横向色块只有 1 像素宽，看不出统一的像素网格；各图层的缩放比例还不一样，前后景的像素粒度对不上。

## 做法

母版与 Codex 分层源图（`assets/title/sources/master-v3/`）都不改，只改派生过程（`pnpm title:art`）：

1. **一个全局网格**：每个图层沿用原来的登记坐标，从源图按线性光面积平均，采样到同一套 640×360 美术像素网格上。1 个美术像素等于 1.5 个逻辑像素，720p 下为 2 个屏幕像素，1080p 下为 3 个。
2. **一套色板**：在 OKLab 空间对所有图层做 k-means，提炼出 64 色，另加 3 个手绘用的保留色。色板写入 `assets/title/palette.json`。透明度只取全透明或全不透明。
3. **清理**：孤立的单像素并入相近的邻色，明显更亮的灯光和反光保留。
4. **手绘精修**（`scripts/title-art/touch.ts`）：看不清的人像海报换成潮汐表，伪文字纸片换成封锁日历（过去的日子打叉，今天加框）；电台面板去噪，电平表重画。
5. **运行纹理存 2 倍**：每个逻辑像素 2 个纹素，所以 1 个美术像素正好 3×3 纹素，任何图层坐标下网格相位都一致。图层坐标、显示尺寸、视差和锚点都不变。移动层直接用线性过滤，不再额外复制一份 2 倍纹理。
6. **PNG 改为索引色**：无损。单文件 HTML 从 6.73MB 降到 2.31MB。

| | 改前 | 改后 |
| --- | --- | --- |
| room 层颜色数 | 58,391 | 59（取自 67 色共享色板） |
| 横向单像素色块占比（按美术像素计） | 95% | 56% |
| `start the game.html` | 6.73 MB | 2.31 MB |

## 尚未完成

- 雨、光点、雾、水面波纹、系船绳仍是 1 个逻辑像素宽，比美术像素（1.5 个逻辑像素）细。
- 电台旋钮区和步枪仍是自动转换的结果，放大后能看出杂乱。
- 字标的做旧颗粒风格和统一网格的像素画不太一致。
- 整体美术仍需用户验收。
