**最高优先规则：离层后立刻进行一次子弹结算，随后冻结该层时间。** 采用合入后的设计：一次结算来源层在途弹丸，处理其合法命中、终止及相关伤害/掉落，再冻结来源层普通战斗。不是直接丢弃所有弹丸，也不是保留悬停弹丸或离层期间持续推进弹丸。全局行动计时、潮汐、已登记追击事件仍按建筑设计推进。保存失败要恢复结算前完整状态，重试不能重复结算。

原设计中的具体数值、表格和验收要求以链接文档为完整规范，本计划不以摘要删减需求。数值属于首版平衡草案，调整必须有记录及试玩证据。原文已经留给后续内容设计的具体阵营命名、事件剧情、黑市货单等仍按其边界处理，不虚构成已定稿内容。

## 2. 交付与实施顺序

一个总 PR 持续承接以下阶段，可分阶段提交便于审阅；全部实现并完成必要验收前保持 Draft／待实现。不要把此计划作为“功能已完成”合入。开始代码工作时重新获取最新 main，保留已接受修复并处理生成物冲突。

依赖顺序：M0 状态与兼容基础 → M1 建筑规则 → M2 换层与追击 → M3/M4 RPG 规则 → M5 基地与离线系统 → M6 商场内容 → M7 全系统验收。商场制图可在基础开发期间准备，正式运行必须接入同一套世界和存档系统。

- [x] 入口主动交互，一次新按下只切一次；指定落点优先，两格（64 像素）圆内按距离、行、列搜索，校验完整身体和活人物占位；无落点不切层、不结算来源子弹。

- [x] 玩家已进入目标层，不受来源层弹丸跨层伤害；结算后来源层无在途弹丸，返回不重新飞行或再计算命中。
- [x] 来源/目标地图、角色、弹丸结算结果、追击候选与取消同一次持久化；失败回滚弹丸、生命、计杀和掉落，成功后才发布画面。
- [x] 只有存活且实际目击换层的敌人登记事件；按可走路径长度/当前正速度加 1 秒进入最后目击目标层；仅听声、旧警觉或无路径不得传送。
