### F07 / F11 普通 Phaser 局内画面（建筑区、商场）

改在 `src/game.ts` 和新的 `src/space-guide.ts`；经典模式（无室内）不变，`src/raid-runtime/*` 未改。

- 屋顶改为完全不透明。原来透明度 .97，屋内敌人移动时能隐约看到（实测 1920×1080 下 3,848 个像素变化），现在为 0。
- 门有按朝向画的指引：关门是沙色角框加门板，开门是绿色角框、贴门框的门板和穿过门洞的双向箭头，状态未知时为灰色。竖墙上的门不再画成横挡在通道上的细条，也不再和家具方块一样。
- 门的格子或任一侧门口在屋顶外时，指引画在屋顶之上，所以站在正门外就能看到关着的正门（原来被屋顶盖住，只剩「E 开门」提示）；只有进屋才知道的门显示灰色，不暴露隐藏房间之间的门开关。
- 指引分两层：地面层在敌人、物资、子弹之下（门口的敌人仍画在指引上面），屋顶上方的副本按已画屋顶裁切，只出现在本来就被屋顶盖住的地方。
- 楼梯加上下三角，目的地标签避开房名，用像素字体，不再和房名叠成「褪色居民[下楼 · 地下]上楼 · 二楼」。标签留在地面层；压到屋顶的部分另画一份按屋顶裁切的副本，所以既能在屋顶上看到，也不会挡住旁边可见地面上的敌人。
- 玩家画在屋顶之上，贴墙时不再被屋顶边缘切掉枪口；敌人、物资、尸体、特效和子弹仍在屋顶之下。
- 「爆头」字样原来画在屋顶之上，隔窗射击屋内敌人会暴露位置；现在按屏幕上实际画出的屋顶判断，敌人被盖住时不显示，已显示的字在屋顶合上时立即隐藏。同层的门开关等重绘不再提前清掉可见的「爆头」字，只有换层时才清理，避免借此察觉隐藏房间里的动静。

### F08 倒退与侧移步态，触屏朝向

- 2.5D 样板（城中村；商场 2.5D 复用同一段 `syncActor`）：倒退时身体仍朝瞄准方向，播放反向短步（帧 3、0、1、0）；侧移时身体向移动方向转最多 45°（瞄准东、向南走显示东南身体），武器和手臂仍跟瞄准。前进和站立与原来完全一致；死亡和倒地仍朝瞄准方向。90° 两侧各留 15° 缓冲，瞄准在侧移时小幅抖动不会来回翻身。规则在纯函数 `src/gait.ts`，`src/coast-view/scene.ts` 只改一行 import、`ActorGfx` 一个字段和 `syncActor` 几行。

- 「急停」没有采用：两套移动都是松手即停、没有惯性，原来的问题出在画面，不在移动规则。

### F12 清空存档，重新开始

- 确认后依次：先过与导入相同的写入检查（另一个窗口接管、无锁、行动中、结算未保存、基地写入未完成都会拒绝，什么都不写）；把当前存档另存到本机 `escape-bincov.reset-copy.v1`；下载一份备份；最后通过现有导入流程一次性写入新开局。写入失败按原规则回滚，原存档不变。

- 主存档格式和键不变；旧版迁移时保留的原始字节随记录保留。主菜单、旧版页签和无法读取的存档不提供清空。

### F12 / F04 破产救济放宽

改在 `src/domain.ts` 的 `grantRelief`；原规则（没有枪且现金低于 ¥200）保留，新增两条，只会更宽松：

- 规则一：没有枪，并且现金加上仓库、背包、安全箱里能卖的东西也买不起一把旧式手枪（¥320），发原来的救济手枪、12 发子弹和绷带。
- 规则二：拥有的枪只有救济手枪，哪里都没有 9mm（含弹匣和待领救济），并且全部卖掉也买不起一包 9mm（¥84，由数据推出），补 12 发救济弹。
- 估算可卖价值时不算救济物资和未完成任务仍需要的物资；佩戴中的饰品和工作台队列里的现金、材料、成品也不算，这只会让救济更宽松，已写入 `docs/PLAYING.md`。
- 存档格式、发放顺序（背包、仓库、待领）、不重复发放和待领队列不变；救济物资仍不能卖、死亡丢失；行动中不发。
- 原来固定「现金 ¥200 不发救济」的测试按新规则改为发放，并补上「¥320 不发」。

已确认的受困情况：S1 没枪、现金 ¥200–319（原来无救）；S2 只有救济枪、没子弹、买不起一包（原来撤离反而比死亡更糟）；S3 有枪没子弹、¥60，卖枪到 ¥210 后（原来无救）。三种现在都能得到救济；¥320 仍不发。对比表见 [relief/relief-outcomes.md](relief/relief-outcomes.md)。

## 兼容性与风险

- 存档：主记录 `escape-bincov.session.v2` 的格式和键不变。新增本机键 `escape-bincov.reset-copy.v1` 只存清空前的存档文本，不参与多窗口冲突判断；读取失败或空间不足时清空会在写主档前停止。救济补发仍在原白名单与上限内。
- 离线：没有新增依赖、网络请求或外部资源；生成物由 `pnpm package` 重建。
- 规则变化：救济放宽和触屏朝向是维护者本轮确认的规则改动；卖掉最后一把枪可能在同一次结算后立即收到救济，这是规则一的预期结果。
- 与商场 2.5D 并行工作：只有 F08 不可避免地改了 `src/coast-view/scene.ts`，位置避开了商场分支已改的区域（import 放在 `./fx` 之后，只动 `ActorGfx` 和 `syncActor`）；其余改动都不在商场会话的文件列表里。生成物（`dist/`、`start the game.html`、`release/`、发布清单）后合并的一方需要重新打包。Phaser 商场画面会随本次改动变成不透明屋顶、楼梯三角与标签、玩家在屋顶之上。
