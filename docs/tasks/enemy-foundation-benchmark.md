# 敌人基础能力 EN-04：可重复 Runtime 测量

承接 [Issue #78](https://github.com/xuys2025/escape-bincov/issues/78)。固定接受基线 `8ef783f02b867c520e2a4e8f03e48e6a8cc7d02c`。入口：[脚本](../../scripts/enemy-benchmark.ts)、[输入与内存存档夹具](../../tests/fixtures/enemy-benchmark.ts)、[夹具回归](../../tests/enemy-benchmark.test.ts)。

这是有界、离线、无 DOM 的 Node 测量，运行真实 `CoastRaidRuntime`、真实敌人 AI、内存 `SaveSession`，包含 Runtime 的发布与定期存档开销。它不测浏览器绘制、纹理、GPU、真实帧率或自然游玩表现；不替代验证矩阵中的 `pnpm test:play`，也没有缩短该套件约 10 分钟和训练真实 120 秒要求。

## 输入协议与恢复

`enemy-runtime-v1` 默认种子 42，每例 12 模拟秒，经典、建筑、商场布局三版各以 20/60/5 Hz 调用 `advance`，同例完整重复两遍，共 18 次。Hz 是脚本提供的调用频率；Runtime 仍按自身时钟划分子步。每次从正式新档部署；不冻结 AI、不增加敌人、不用测试驱动。角色每三秒换方向走小方形，始终瞄准当前最近活敌，每秒按一次开火，每四秒请求换弹。无碰撞绕行、自动治疗或无敌，因此它不是通关脚本。

每例中点主动提交检查点，将已保存的字节复制到独立内存存储，再以新 `SaveSession` 初始化、恢复行动、创建新 Runtime，比较完整持久世界与身体快照。复制存储避免引入第二个写者干扰原行动。恢复成功不表示验证了写入失败、多窗口冲突或所有历史存档；这些由对应存档回归负责。

行为签名包含初始、逐秒与最终完整活动快照，以及每次调用的全部事件；包含 AI 路径、位置、计时器、RNG、身体状态、弹药、敌人、掉落与容器。仅将生成的 `runId`（含嵌入实体 ID）和物品 ID 替换成保留引用关系的稳定标识，不四舍五入数值。末态另有独立 SHA-256。不同调用频率的路线、伤害、浮点累计可以不同；只对相同种子、输入策略和调用序列判断重复确定性。

## 执行与 A/B

在依赖已安装的任务工作树运行；不需要浏览器或服务器，也不增加依赖：

```powershell
node --import tsx scripts/enemy-benchmark.ts --source-root=D:\bincov\enemy-baseline-8ef783f --out=test-results/enemy-baseline-8ef783f.json
node --import tsx scripts/enemy-benchmark.ts --out=test-results/enemy-head.json --compare=test-results/enemy-baseline-8ef783f.json
node --import tsx --test tests/enemy-benchmark.test.ts
```

`--source-root` 只加载指定检出的源码，同一份脚本与夹具用于两端，旧基线无需具有此工具；指定目录必须是可信且具有依赖的完整检出。Git 只对该命令的显式目录传 `safe.directory`，不修改全局配置或 Git 钩子。可选 `--seconds=2..60`、`--seed=1..4294967295`；改参数后两端必须重新采样。未指定 `--out` 时 JSON 写到标准输出，进度写到标准错误。

JSON 记录源码 commit、工作树脏状态、Node/OS/CPU、种子、初始活动/全世界敌人数、实体数、调用次数、模拟秒数、Runtime `advance` 总耗时、完整测量实际耗时、峰值活动子弹、写入次数、终态摘要/哈希与恢复结果。`advanceMs` 只累加正式 `advance` 调用；`wallMs` 还含签名计算、中点恢复等测量开销，不含部署与模块加载。重复签名不同、恢复失败、A/B 签名不匹配或样本集合不同都返回非零。时间只报告观察值，不设机器相关通过阈值；两遍包含 JIT/缓存和系统调度差异，不能当作统计显著的提速结论。

本工具为手动 Node 测量入口，未新增 `test:*` 命令或浏览器 CI 套件。短单测只验证夹具 ID 归一化不吞掉数值/引用变化，以及三个正式世界的重复和恢复；完整 12 秒矩阵由上述命令执行。

## 本次实测

2026-10-22，在 Windows `10.0.19045` x64、Intel Core Ultra 5 230F（10 逻辑 CPU）、Node `v24.19.0` 上顺序运行固定干净基线，再运行基于该 commit 的 AI 提取后工作树。实际 Node 位于 `C:\Users\xty\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe`；上述命令中的 `node` 均使用此程序。工作树结果明确记录 `dirty`，不冒充已经提交的 head。

两端各 18 次运行全部重复稳定、全部中点恢复成功；9/9 A/B 的行为与末态完整 SHA-256 都相同，比较命令退出 0。每次均完成约 12 模拟秒，仍在行动中，击杀 1；存档恢复点为约 6 秒。活动/全世界敌人数分别是经典 25/25、建筑 23/25、商场 16/25。每例调用数依次为 240、720、60；全矩阵每端共 216 模拟秒。末态生命值因调用频率不同而不同：经典约 54.8/54.8/68，建筑约 54.784/54.822/62.67，商场约 52.458/52.479/54.206（顺序 20/60/5 Hz），没有将它们判成确定性缺陷。
