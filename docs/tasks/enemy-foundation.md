## 实现与所有权

[制作目录](../../scripts/enemy-catalog-data.ts)不进入游戏包或字体扫描。`pnpm enemy:catalog` 输出对照表，`pnpm enemy:catalog --json --id=raider-melee` 输出单卡；所有卡标为 `design-only`，素材标为 `not-produced`。

[enemy-profile.ts](../../src/enemy-profile.ts)只保存 `scav/salt/creature/elite` 的旧身体、武器、近战/弹丸类别及尸体搜刮次数，不接管 `domain.ts` 的数值和出生规则。未知 ID、继承键与设计 ID 显式拒绝。展示、经典和分层尸体掉落读取同一张表。

[enemy-ai.ts](../../src/raid-runtime/enemy-ai.ts)更新 Runtime 所有的旧敌人状态，沿用原有巡逻、调查、追击、攻击、返回与避潮判断。Runtime 保留随机流、实体 UID、发射/近战事件、伤害、开门候选事务和存档所有权。提取保持判定顺序、随机抽取次数、冷却与路径参数；开门尝试后立即返回，即使保存失败也不继续移动。未改玩家射击，集成后的玩家行为由 #39 的新实现决定。

#79 的子步时间、门保存失败回滚和玩家持续射击剩余飞行时间均保留。旧敌人按子步判断开火，没有玩家扳机的子步内精确触发时刻，其新弹仍沿主线规则推进整步；本次提取不把它改为零飞行时长。新敌人攻击阶段及触发时刻归 EN-02/06 明确定义。独立只读复核与同基线 A/B 未发现此次整合改变旧行为。
