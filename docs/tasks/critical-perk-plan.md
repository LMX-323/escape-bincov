## 结论与范围

**技术上可行，整体复杂度高。** 现有成长、单一行动 Runtime、基地候选事务、检查点和展示层可复用，保持单人离线和现有依赖即可实施。最大工作量是严格存档与旧行动兼容，其次是弹丸时序、屏息输入和 24 项效果的完整验收，不能作为简单改公式交付。

玩法数值仍以[专项规格](../CRITICAL-PERK-DESIGN.md)为准：24 候选、12 节点、永久 15/20/25/30 解锁、各档独立混搭、未暴击概率乘法合并、500 现金重置单属性。没有因拆任务删减范围。首次解锁约 13～25 局只是按每局有效成长 0.4～0.2 推算，实际训练、任务奖励和真人平衡尚未测量。

### 兼容边界

旧行动保持旧暴击、伤害和 RNG 规则直到结算；新规则只从下一次出击启用。原经典无暴击行动也不能半局增加随机暴击。旧档首次升级只初始化空选择集，不代选、不补发训练，现金、物资、成长、任务、生产和活动世界全部保留。

显式区分旧行动身份与损坏新档。弹丸快照至少能还原来源、倍率、屏息目标和该发规则；开枪先扣弹/快照，再清屏息，命中有效敌人才摇暴击。当前层步进与跨层即时结算使用同一结算逻辑，结果、掉落、训练和 RNG 随世界原子保存。

屏息属于瞬时行动状态：真正暂停/恢复清零，在途弹丸快照继续保留。Runtime 内部频繁的 `restoreExpansion` 也是状态同步路径，不能无差别把每次内部同步都解释成“读档恢复”，否则蓄力永远无法增长。失败事务恢复与新建 Runtime 的生命周期必须分别验收。

### 数值与表现边界

聚合与显示共用来源，拒绝非法数值、未知 ID 和冲突的重复来源；不能用字符串原型上的属性当合法配置。近 100% 的浮点结果不等于明确 100% 来源，显示的必定标志须独立判定。每颗霰弹独立抽样，训练按实际损血，匕首和敌人攻击不使用玩家枪械公式。

所有 24 个候选都有接入归属：CP-T05 的力量 8＋体质 8＋装填 2，CP-T04 的技巧暴击/倍率 3，CP-T06 控枪 2，CP-T07 屏息 1。固定奖励相加、同类倍率连乘，状态/buff/Perk 的耐力合计倍率最后限幅。治疗/直接减伤/环境污染等效果各守自己的适用范围，不放大无关恢复或削减持续损伤。
