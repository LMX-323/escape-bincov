- 港口原图恢复到 `(0,24)`；真正延展天空、港口与室内边缘，避免视差移动露出透明条带。

- 调整门窗覆盖范围、电台锚点与尘埃所属图层。船、灯和绳索沿用独立帧动画。
- 暂停动态、窗口失焦或系统减少动态效果时保留当前构图；配对移除场景 shutdown/destroy 回调。
