## 玩家入口与兼容边界

整备页「行动区域」可选择经典沿海封锁区、带居民楼二楼/地下的沿海街区、滨湾商场。经典区域和恢复中的 coast-v1/coast-v2 保留原规则与生成器；新街区/商场出击启用 RPG 身体状态。整备页「走进水产站」可启用安全基地，原菜单整备、交易、任务与导入导出入口仍可使用。

居民楼门两侧可开关，活人物占门洞时不能关门；窗与矮家具挡身体但允许视线和子弹，不能隔窗搜刮或近战。楼层入口需新按 E / 点交互；长按只切一次，旧移动、冲刺、瞄准与攻击要先释放。背包、地图和搜刮继续计时；面板打开时不切层。

切层候选先选择合法目标站位，再结算来源层的有限剩余弹道一次，最后冻结来源普通战斗。目击者沿来源路径和一秒连接延迟追击，途经开门；潮位变化重新寻路或退回安全地面；目标拥挤按抵达时间和 UID 排队。事件与源/目标敌人互斥，HP、冷却、随机状态和尸体归属不因切层重置。只有成功保存才发布门或楼层变化。

身体、临时效果、永久三属性和训练余数持久化。符合条件的负重移动、实际耐力消耗、合格敌伤治疗及枪伤产生训练；同一小范围往返有限额，顶墙、空射、尸体、环境伤、溢出治疗和离线不练级。检查点按累计应得与已入账差额提交，每项单局最多 0.45 进度。普通爆头按已命中轨迹计算中心接近度，每弹丸独立随机乘一次 1.5；面板显示基础暴击与中心最多额外8个百分点。

基地是24×18格安全地图，设休息、医疗、训练、工作台和黑市五固定点，另有仓库、修理铺、电台和出击入口。免费恢复和治疗不消耗物资；设施等级替代上级效果。训练区选项目后实际走动，每120秒有效练习获得一次收益，共享已保存十分钟窗口上限。设施管理也可从站内菜单进入。

工作台仅支持三份已定义配方。入队支付一次并锁定时长，队列容量等于工作台等级，成品区最多三批。只可取消尚未执行的批次，全额退款必须能装入仓库；整批领取必须全装下。成品区满时停工，不储蓄停工时间；领取空出位置后，同一事务接纳已完成的堵塞批次。基地/行动/暂停/离线都可推进已付款生产，只有基地累计恢复；待结算期间不回血。时钟回拨不降低游标，长离线按有限事件边界处理。

## 存档格式与实现模块

主档键保持 `escape-bincov.session.v2`。M0 的 session v4 外封套不变；RPG 正式组件为 `ExpansionState.version=2`、`LayeredRaid.version=2`，兼容读取 M0 组件v1。v2 增加独立护符栏、奖励收据、最后精神冲击时间、一次地图事件结果及敌弹来源。新字段必需，未知字段/版本、重复UID、伪造配方付款、缺少地图或实体所有权不完整都拒绝覆盖。旧实际 HTML 拒绝v4，升级前原始字节保留一次。活动和待结算备份保留全地图、身体、成长、设施、队列及时间游标。新行动的生成物采用行动ID与序号组成的身份，保留战利品后重复同种子出击不会与新物资冲突；原组件和旧未加前缀身份仍可读取。护符换装、卸下保持同一UID。

| 模块 | 责任 |
| --- | --- |
| `spatial.ts` / `building-world.ts` / `mall-world.ts` | 各图几何、门窗、交互、合法落点、一次全局投放 |
| `layer-transition.ts` / `pursuit.ts` | 共用有限弹道、实际伤害、离层事务、事件推进与移交 |
| `rpg.ts` / `reputation-luck.ts` | 身体倍率、效果、训练、爆头、通用奖励/价格/资格、幸运单次生成 |
| `base.ts` / `production-clock.ts` | 成本、三配方、取消/领取、免费恢复和有限现实时间推进 |
| `expansion-state.ts` / `session.ts` | 严格校验、不透明候选票据、持久化提交、完整回滚/结算/导入 |
| `game.ts` / `base-scene.ts` / `ui.ts` / `art.ts` | Phaser表现、基地走动、原生控件、程序像素陈设与屋顶 |

规则模块无 DOM/Phaser 依赖。场景端仅捕获/恢复同一完整状态，不另存人物或单层世界。候选提交前推进旧设施倍率下的现实时间；失败保留原存档与随机候选，重试不重抽。公开地图注册表只包含审核过的布局，不从导入 JSON 加载几何。

## 内容与首版平衡决策

- 旧20件物品和原海岸生成顺序保留。新增清洁布料、镇痛片、专注剂、三属性针剂、两护符和两香包，总目录30件。布料沿设计定价；镇痛片/专注剂初设售价80/140，稀有用品不直接零价出售。重量、堆叠及稀有来源是首版实现取值，尚未经过真人经济复核。
- 新街区/商场从原60份记录中，非任务/关键资源随机记录4%换为稀有用品，随后10%换为布料；替换不新增基础份数。公共修理铺追加布料，公共卫生所追加镇痛片和专注剂；经典模式公共供货不改。幸运额外watch/pearl与减产单列，默认L=1保持基础中性。
- 幸运数值和事件概率不显示给玩家。护符占独立装备栏并计入重量；同类限时用品刷新。每次原生成单元判定一次，开箱、放回和刷新不再抽取；额外物资满箱时同点落地且同次提交。
- 通用阵营价格、门槛、奖励收据和多阵营原子结算已实现；依原文不命名新阵营，不把旧三任务绑定阵营，不回溯发属性/声望。地图事件仅保存一次方向判定，具体剧情、奖励与黑市货单/预约仍属于原规范明确留后的内容。
- 黑市的成功撤离海珠凭据仅由新增完整终局记录授予；旧静态库存不自动证明撤离来源。携普通库存海珠再次成功撤离可取得凭据，L1交付只消费成本表同一颗，救济不满足条件。
- 原游戏无独立枪械后座系统，技巧与精神/疼痛的后座倍率应用于原有散布；不额外新增武器模型。小范围计量采用保存的路线锚点和每分钟局部额度，防止刷新换层重置。
