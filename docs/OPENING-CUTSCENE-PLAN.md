# 开场动画制作方案

> **状态：2026-10-15 维护者确认，开始制作。** 分镜、台词和与主线的衔接见[分镜稿](OPENING-CUTSCENE-SCRIPT.md)，确认的内容见第 10 节。实现另开新 PR；本 PR 只有文档，当前游戏、存档和发布包都没有改。

## 1. 范围

要做的：

- 一段约 2 分 20 秒的开场动画，内容按分镜稿分三段（台风夜、十六天、第十六天），最后一张「第十七天」字卡接进院子。
- 新存档第一次点「进入水产站」时自动播放，随时能跳过；主菜单加「序幕」，随时能重看。
- 不配音。台词、旁白和带信息的声音都用字幕；声音用 Web Audio 合成，跟随「游戏音量」。

不做的：

- 视频文件、配音、可选分支、剧情状态存档。
- 改院子、行动、商店、存档格式或任何数值。
- 动画里出现的远汐号、水产站人物等，不因此提前接入别的玩法。

## 2. 表现方式

像素“动态漫画”：每个镜头是一张分层像素画，加少量循环动画（雨、闪电、手电光、人物 2～6 帧的动作）和镜头横移，靠剪辑和字幕推进。这样选，是因为：

1. 和主菜单同一套 640×360 美术网格、同一份共享色板（`assets/title/palette.json`，67 色），画风接得上。
2. 游戏要单文件离线运行，放不进视频；索引色 PNG 按镜头分层，体积可控。
3. 人物帧数少，美术量能控制在一批之内。

播放器建议做成独立的 Canvas 2D（放在 `src/opening/`），不进 Phaser 场景，也不用 Pixi：

- 不依赖 WebGL。院子在没有 WebGL 的设备上会退回旧页签，开场动画在这些设备上同样能播。
- 一块画布、一组图片，播完全部释放，避开 Pixi 渲染资源释放的老问题（见 [#32](https://github.com/xuys2025/escape-bincov/issues/32) 的 F20 记录）。
- 以后 Phaser 下线，这部分不用迁移。

字幕和「跳过」「暂停」按钮用 HTML 叠在画布上：字清楚，读屏软件能读，按钮有正常的焦点和触控面积。

## 3. 播放规则

| 情况 | 行为 |
| --- | --- |
| 新存档（累计出击 0，没有待恢复的行动），第一次点「进入水产站」 | 自动播放；播完或跳过后按原流程进入水产站（院子；没有 WebGL 时为旧页签） |
| 同一页面里再次点「进入水产站」 | 不再自动播放 |
| 已有出击记录，或有待恢复的行动 | 不自动播放；「继续上次行动」照旧 |
| 主菜单「序幕」 | 任何存档都能看；播完或跳过后回到主菜单 |
| 跳过 | 右上角「跳过」按钮或 Esc，立即结束，去向同上 |
| 暂停 | 「暂停」按钮或空格。打开时焦点在「暂停」上，空格不会误触「跳过」。页面隐藏、窗口失去焦点时自动暂停，回来后点继续 |
| 主菜单「动态景物」关，或系统开启“减少动态效果” | 不横移、不抖动、不闪电，雨停在一帧；镜头之间淡入淡出；字幕和时长不变 |
| 音量 | 跟随「游戏音量」；为 0 时照常播放，带信息的声音有字幕 |

“看过没有”只记在当前页面的内存里：不写存档，不新增 localStorage 键。新存档在第一次出击前刷新页面，会再自动播一次，可以直接跳过。以后剧情状态并入主档时，再决定要不要把“看过开场”一起记下（[剧情转化工作方案](NARRATIVE-ADAPTATION-PLAN.md) 4.2 规定剧情不另起存储键）。

闪光安全：任何模式下，画面每秒闪烁不超过 3 次，不做整屏纯白或大面积饱和红闪；闪电只把画面提亮一档。

## 4. 画面规格

- **网格与放大**：画面按 640×360 美术像素制作，一个美术像素存成一个纹素。1280×720 下放大 2 倍，1920×1080 下 3 倍；其他尺寸取能放下的最大整数倍，四周留黑边；连 1 倍都放不下（竖屏手机）时等比缩小，此时允许平滑。横移按整美术像素走，不出现半像素糊边。
- **色板**：从主菜单的 67 色共享色板出发。夜景以冷色为主；暖色只给手机屏、手电和水产站的光；正红只用在怪物的眼睛。确需新颜色可以加，新增不超过 32 个，登记在开场的色板文件里（前 67 色照抄主菜单，顺序不变）。透明度只有全透明和不透明两种。
- **构图**：画面下方约五分之一留给字幕，关键动作不放进这块。竖屏时字幕放到画面下方的黑边里。
- **人物**：中景人物高约 60～90 美术像素；特写单独画，不把中景帧放大。
- **怪物**：和游戏里的潮蚀生物用同一套造型：弓背、粗胳膊、白色盐晶、红眼（参照 `src/coast-view/art/actors.ts` 的 `paintCreature`）。
- **字幕**：用游戏点阵字 Bincov Text，16px 或其整数倍；一行不超过 22 个字，最多两行；说话人前缀用另一种颜色。按分镜稿统计，现有字体子集缺 68 个字，要按[字体说明](../assets/fonts/README.md)用固定的上游字体重新子集化，构建会检查覆盖。
- **雨**：在 640×360 网格上程序生成或另画，不直接搬主菜单的雨（那套比美术像素细，见[主菜单像素网格](title-pixel-grid/README.md)的“尚未完成”）。

## 7. 技术方案

建议结构如下；实现时可以调整，职责边界不变。

| 模块 | 职责 |
| --- | --- |
| `src/opening/timeline.ts` | 纯数据：镜头、字幕、声音事件和时长，以毫秒计；不碰 DOM |
| `src/opening/player.ts` | 时钟、暂停、跳过、减少动态时的替代；按时间取当前镜头和字幕 |
| `src/opening/render.ts` | Canvas 2D 绘制分层画面、横移、闪电提亮、手电遮罩 |
| `src/opening/overlay.ts` | HTML 字幕、跳过和暂停按钮、读屏播报 |
| `src/opening/sound.ts` | 第 6 节的合成音 |
| `src/opening/assets.ts` | 导入 `assets/opening/*.png`；开始播放时解码，结束后释放 |

接入点：

- `src/ui.ts` 的 `enter` 分支：按第 3 节判断要不要先播，结束回调里执行原来的进入水产站逻辑（`enterStation()` 或旧页签），原逻辑本身不改。
- `src/title-screen.ts` 的菜单加「序幕」，与「行动指南」同一种按钮。
- 播放时让主菜单的 Phaser 循环休眠（院子打开时也是这样做的），结束后按原流程切换。
- 测试接口只在 `?test=1` 下暴露：当前镜头、字幕、暂停状态和快进。

构建与测试：

- `assets/opening/manifest.json` 记录每张图的文件名、尺寸、颜色数和 SHA-256；`scripts/build.mjs` 照主菜单、院子的做法检查导入与清单一致。
- 时间轴单测放在 `tests/`：镜头首尾相接，每条字幕的停留时长符合 OP-06，引用的素材都存在，字幕文本与分镜稿一致。
- 新增浏览器专项 `pnpm test:opening`，覆盖第 9 节的验收项；放进 CI 的 title 组，同时更新 `scripts/ci/policy.test.mjs` 的覆盖清单和 [CI 说明](CI.md)。
- 改了源码就按开发手册运行 `pnpm package`，提交两份 HTML、两个 ZIP 和发布清单。

存档：动画全程不读写存档，只读累计出击次数和有没有待恢复的行动。
