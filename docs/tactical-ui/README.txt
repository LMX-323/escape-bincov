实现
- 整备按随身装备、背包、仓库排列。安全箱在装备下方，物品操作位于固定底栏。
- 54px / 80px 格位分别适配 720p / 1080p；战斗仍为 960×540 逻辑画布整数缩放。
- 搜刮把自己的物品置于左侧、来源容器置于右侧，拖动使用实际格位坐标；行动继续计时。
- 商人左侧展示库存和用途，右侧展示玩家仓库；买卖沿用原有会话事务和失败回滚。
- 字体 B 为寒蝉点阵体 16px Regular 的 OFL 字符子集，按许可更名 Bincov Text。
  物品名称/数量、主要正文采用原生 16px；短小元信息采用系统字体。字体内嵌，构建检查字集与哈希。
- 所有像素素材由源码逐笔定义、共享材质色阶。库存按物体比例绘制，地面物资采用实体轮廓。
  原生边缘使用整数像素，无模糊滤镜；高亮主要服务选择、交互与物品区分。
- 新世界纹理仍使用同一地图/碰撞格，不增加会误导通行判断的地面障碍；静态纹理缓存并随场景释放。

逐项物品检查（20 种；另检查 24px/32px 紧凑图、原生与 3× 图集、灰度和库存旋转）
knife：明亮单刃、护手、皮柄；旋转后不裁切。
pistol：短滑套、扳机护圈、斜握把，与两种长枪区分。
shotgun：并排枪管、木枪托、前护木，无卡宾枪弹匣。
carbine：长枪管、机匣和独立弹匣，保持与双管枪不同轮廓。
ammo9：短圆头弹；shell：平头红壳霰弹；ammoR：尖头细颈步枪弹。
bandage：密封方袋与卷纱中心；medkit：红色提手包与医疗十字。
antidote：矮宽药瓶与绿色叶形标签；water：透明窄瓶、瓶颈与水位。
food：椭圆金属罐顶与鱼形标签。
scrap：偏心泵壳与安装耳；wire：中空线圈与外露铜芯；fuse：陶瓷管与两端金属帽。
battery：高方盒、分离接线柱、正负极标签。
watch：吊环、表壳、指针；pearl：无吊环的圆润珠体，以剪影区分。
sample：封存罐、红色封条与液体；ledger：书脊、展开书页、红书签。

其他素材检查
玩家（匕首/手枪/双管/卡宾）、拾荒者、防水衣敌人、重装敌人、潮生物：
检查正交和斜向共八个朝向的身体、装备与朝向轮廓；四类尸体使用独立倒地图。
箱子满/空：金属箱与锁扣形态变化；记录：纸页折角。商人头像：修理工帽与医务衣领。
场景：城中村、水产市场、观测站、旧港、泵房、水产站及高低潮。
逐类查看墙窗、鱼货、冰箱、电机、工具、货架、电箱、仪表、样本架、管路、绳圈和船体。
装饰箱不使用搜刮箱的黄铜锁扣。地面散落物不再只靠同形包裹的小色块区分。
以上是逐图视觉审查与程序检查，不等于玩家识别率或审美盲测。
