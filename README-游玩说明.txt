逃离滨科夫 · Escape Bincov

如何启动
1. 如果收到 ZIP，请先把它解压到一个固定文件夹。
2. 双击 start the game.html，用桌面版 Chrome 或 Edge 打开。
3. 点击「进入水产站」，整备后点击「出击」。

start the game.html 就是完整游戏，不是指向作者电脑的快捷方式。
它包含全部游戏代码、画面和声音；无需安装、联网、Node.js 或服务器。
可以单独分享这个 HTML，也可以分享整个 ZIP；文件夹可改名或放到其他盘。
若双击打开了编辑器，请右键文件 → 打开方式 → Chrome 或 Edge。

基本操作
WASD 移动；鼠标瞄准；左键射击；右键精瞄；Shift 冲刺。
R 换弹；E 拾取/阅读；撤离圈内保持静止并按住 E 满 3 秒撤离。
Tab 背包；Q 治疗；M 地图；1 主武器；2 匕首；Esc 暂停。
背包和地图打开时游戏继续。行动限时 10 分钟，5 分钟时潮位翻转。

存档与分享
每个人的进度保存在自己的浏览器中，此分享包不包含作者或其他人的存档。
请保持同一浏览器及同一文件路径继续游玩；移动文件、更换浏览器或清理
浏览器数据可能对应另一份存档。不要长期从压缩包预览中的临时路径启动。
关闭或刷新未结算的行动会按撤离失败处理；安全箱里的物品保留。
原项目 dist/index.html 仍可使用；如其中已有进度，可继续从原路径打开。

当前为本地个人原型，仅支持桌面键鼠，不支持手机、联网或多人。
画面与声音为原创程序素材；Phaser 等组件的许可已内联到游戏 HTML。


0.1.1 存档与迁移
水产站页新增“导出存档”和“导入存档”。更换网页域名、浏览器或文件路径前先导出；导入需确认覆盖。
结算保存失败会停留在“结算尚未保存”面板，可重试或下载包含本次成果的结算备份。保存或备份完成前不要关闭页面。
旧版本玩家先把新版 HTML 覆盖到原游戏文件的相同路径，再使用原浏览器打开并导出。
网页版本仍为单人键鼠游戏，尚未提供手机触控或多人联机。
